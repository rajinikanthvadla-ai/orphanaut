### What's new in 2.2

- Tick resources with checkboxes, or use Select all
- New resource map that shows how each resource is connected
- AWS, Azure and Google Cloud logos
- Cleaner layout and shorter text

### Downloads

- Windows: `Orphanaut-Setup-Windows.exe` or `Orphanaut-Windows-Portable.zip`
- Mac (Apple Silicon): `Orphanaut-macOS-AppleSilicon.dmg`
- Mac (Intel): `Orphanaut-macOS-Intel.dmg`

If you're on 2.1.2, the app will offer this update on its own.
