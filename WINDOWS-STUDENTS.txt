Orphanaut for Windows

Install
1. Download Orphanaut-Setup-Windows.exe from the Releases page.
2. Run it. If SmartScreen shows up, click "More info" and then "Run anyway".
3. Open Orphanaut from the Start menu.

Portable version
1. Download Orphanaut-Windows-Portable.zip.
2. Extract it to a folder like C:\Orphanaut.
3. Run Orphanaut.exe from that folder.

Getting started
1. Pick AWS, Azure or Google Cloud at the top.
2. Sign in on the left.
3. Choose your regions and click Scan.
4. Tick what you want to remove and click Delete.
Press F1 for help.

If the app doesn't open
- Windows Security > Virus & threat protection > Protection history.
  If Orphanaut was blocked, choose "Allow on device".
- The error log is at %USERPROFILE%\Orphanaut\startup.log
